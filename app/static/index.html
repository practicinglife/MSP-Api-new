🚫 Offboard Device

⚠ This will decommission the device from selected platforms. This action may be irreversible.

Multi-Step Offboard Process:
Step 1 — Asio Uninstall (max 5 devices per batch): Removes SentinelOne + ScreenConnect via Asio automation script.
Step 2 — ESET Removal (optional): Searches endpoints for ESET products, then triggers uninstall script or flags for manual removal.
Step 3 — Other Platforms: Falls back to direct API offboard (e.g. SentinelOne).
Asio limits uninstall to 5 devices per trigger. Larger batches are split automatically.
